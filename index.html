1 How to Write a Paper in a Weekend — Prof. Pete Carr
Caption: Don't procrastinate. Outline big picture first. Start with Methods (easiest) → Results/Discussion logical sequence → Conclusion numbered → Abstract + Acknowledgements → Intro LAST (hardest) → Edit English + science → References last.
2 Peer-Reviewed Paper — Full Roadmap
Caption: Title = clickbait — power words, tell exactly what done, no acronyms. Intro = broad→narrow→why study needed. Abstract ~300 words with key results. Conclusion 2-3 points. Send early draft to supervisor — don't wait perfection.
3 Research Methods vs Methodology — Tools vs Reasoning
Caption: Methods = tools (survey, interview, experiment, simulation). Methodology = system + reasoning why chosen. Covers quantitative/qualitative, sampling, bias checklist, design→data→analysis→ethics→peer review. Biology no lab options included.
4 How to Read Research Papers — Bird's eye → Swoop → Street
Caption: Don't read linear. 1 Bird's-eye 5-10min (title, abstract, headings, conclusion) 2 Swoop (figures, tables, core findings) 3 Street view (critical deep read). Rubber duck method if stuck. Saves 80% time.
5 Research Workflow — Idea to Publication
Caption: Practical workflow — idea validation → gap finding → hypothesis → methods → execution → writing → revision → journal selection. Complements 1-4 — shows how to track progress.
